# 宅配ドライバーログ App Store 掲載文（日本語）

## 名前（30字以内）
宅配ドライバーログ

## サブタイトル（30字以内）
件数・売上・走行を毎日かんたん記録

## プロモーションテキスト（170字以内）
件数を入れるだけで売上を自動計算。走行距離や給油、出庫・入庫時刻もまとめて記録し、月間・年間の売上をカレンダーでひと目で確認できます。ログイン不要、記録はすべてiPhoneの中に保存されます。

## 説明
宅配・軽貨物ドライバーのための、日報と売上の記録アプリです。
毎日の入力は10〜20秒。配完・集荷などの件数を入れるだけで、その日の売上を自動で計算します。

■ 毎日の記録
・配完・集荷など、売上項目ごとの件数を入力（項目は最大5つ）
・出発・到着メーターから走行距離を自動計算
・給油金額と、給油を差し引いた金額
・出庫・入庫時刻から稼働時間を計算
・メモ、休日の登録
・入力はその場で自動保存

■ カレンダーと集計
・月間カレンダーに、売上・走行距離・件数など好きな3項目を表示
・祝日、休日、楽天の大型セール（お買い物マラソン、ブラックフライデーなど）も表示
・月間・年間の売上、1日平均の件数・売上を自動集計
・カレンダーをA4横・1か月1枚のPDFにして、そのまま印刷

■ 自分の仕事に合わせて
・売上項目の名前と単価は自由に設定
・単価を変えても、過去の売上はそのまま
・勤務時間・給油・走行距離の入力欄は、使わなければ非表示に
・オイル・エレメントの交換時期を、残りkmでお知らせ

■ 書き出しとバックアップ
・業務レポートPDFを期間を選んで作成
・バックアップJSONで記録を保管

■ 安心して使える
・ログインや会員登録は不要
・記録はすべてiPhoneの中に保存され、開発者のサーバーには送られません

※売上の計算は入力した件数と単価にもとづく目安です。

## 審査メモ（App Review向け・英語）
No account or login is required. All records are stored only on the device (AsyncStorage); nothing is sent to the developer's server.
The only network access is a daily download of a public JSON file of Rakuten sale dates (https://dai0805-h.github.io/takuhai-calendar-feed/calendar-events.json), which is shown on the calendar. No user data is sent.
How to try: open the 記録 (Record) tab, enter counts for 配完/集荷 and odometer values; the day's sales are calculated from the unit prices set in 設定 (Settings) > 売上項目・単価 (they start at 0 yen, so set a price first). The カレンダー (Calendar) tab shows monthly totals and can export a one-page A4 calendar PDF.
